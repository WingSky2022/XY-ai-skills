  • 「评分」是一堂对单次作业的学分评定，取值 3 / 4 / 5 / 6，6 分为满分；— 表示该条尚无评分（当前 0 条）。
  • 逐条评分合计 0 分 ≠ 账户总学分 0。账户侧另有「额外学分」scoreExtra=0，且学分还包含非作业来源；正式口径请以账户学分为准，本清单只反映作业评分本身。
