# Capability Workbench（双三角 × Feature 能力诊断工作台）

> **来源与受众声明**：本技能萃取自以太一堂《AI 双三角》与《AI 基本功第一课：Feature 思维》（Truman）课程框架。**仅限以太一堂学员内部使用，请勿外传。**

## 一句话定义

**扫描用户的多个项目 → 人工门控（Gate）决断 → 生成「双三角 × Feature 周期律」能力画像 → 注入模板产出单文件展示工作台。**

## 核心定位（必读）

本技能是**引导式多阶段流程**，不是一次性自动生成器：

1. **人是主体**：审美、创造力、场景的价值判断永远由被评者本人做（Gate 环节），AI 只判存在性、完备性与结构。
2. **不清楚就问**：扫描或决断中遇到模糊点，**标记后主动向用户提问，等回答后再继续**——不要替用户做价值判断，不要用假设冒充事实。
3. **证据分级**：每个结论携带置信档（本地实测 / 文档级 / 索引级 / 用户口径），信息不足用「假设标记」，不断言。

## 框架速览

**双三角六要素**（完备度分级：完备 / 部分 / 0 / 待确认——只判存在性，不判质量水平）：

| 人类三角 | 关键问题 | AI 三角 | 关键问题 |
|---|---|---|---|
| 审美 | 好结果长什么样？质量标准载体在哪？ | 基本功 | 用了哪些 AI 特性/工具？ |
| 体系 | 有无可复用框架与规范？ | 数据 | 有什么高质量可复用输入？ |
| 创造力 | 有无突破惯例的差异化线索？ | 场景 | 目标用户/应用域/价值线索？ |

**Feature 周期律**：纵轴 L1 基础模型层 → L5 硅基组织层，横轴 A 角色身份 / B 上下文资源 / C 能力环境 / D 任务协作；全表见 `references/feature-table.md`（含「借假修真」场景栏）。

**沉淀六阶段**：收藏 → 试用 → 验证 → 内核 → 边界 → 肌肉记忆。

## 执行流程（五阶段 + 可选深扫）

整体节奏：先扫描取证、再门控决断、后汇总成像。每阶段产物都是下一阶段的输入。

### 阶段 0 · 准备
- 向用户确认：**项目路径集合**、受众口径（仅自用 / 可对外展示——影响敏感内容取舍）、扫描深度。
- 读 `references/scan-playbook.md` 获取判据表与批次规则。

### 阶段 1 · 扫描（可并行，可降级）
- 按路径集合逐项目扫描：结构 + 说明文档 + git 历史 + 关键 frontmatter；**双三角六要素完备度 + Feature 判读（候选 Feature / 周期律归位 / 迭代证据 / 沉淀阶段 / 思维诊断）**。
- 产出：每项目一份扫描报告（六要素判级表 + 证据摘要 + Gate 待决断清单）。
- 执行方式**按环境能力自适应**：多代理并行可用则并行；否则单代理串行逐项目——两者产物结构一致。

### 阶段 2 · 人工门控（强制，不可跳过）
- 汇总全部「Gate 待决断清单」，按 `references/gate-cards.md` 的操作卡逐条向用户提问（封闭式，人只答最小集合）。
- **收齐回答前不得进入阶段 3 的定稿**；用户未回答的条目保留「待决断」并如实标注。

### 阶段 3 · 汇总
- 按决断结果修正判级 → 产出能力评估汇总（段位定位 + 画像 + 差距与路径）。
- 按 `references/data-schema.md` 生成数据文件 `xy_capability_data.json`（或按被评者命名）。

### 阶段 4 ·（可选）任务现场深扫
- 若用户愿提供 1–3 个真实 AI 协作任务的现场材料（聊天导出 / prompt 迭代 / 失败案例），做「使用质量」深扫：工具思维 vs Feature 思维诊断、归因破局、三张牌使用痕迹。
- 用户不提供则跳过，并在报告中声明该维度未覆盖。

### 阶段 5 · 工作台生成
- 用 `assets/workbench-template.html`（含 `__DATA_JSON__` 占位符）注入数据 JSON，产出单文件 `index.html`。
- 构建与自检见 `assets/build.md`；视觉规范见 `references/style-guide.md`。

## 硬纪律

1. **Gate 不可代答**：审美/创造力/场景的价值与归属判断必须留给人。
2. **待确认纪律**：证据不足标「待确认」，不留空、不虚构分数。
3. **不可达 ≠ 缺失**：扫不到的路径标「待确认 + Windows 源未验证」，禁止写成 0。
4. **对外友好口径**：受众选「可对外展示」时，差距清单与低分细节不进工作台，只留在评估文档。
5. **受众限定**：本技能及产物仅限以太一堂学员使用。
