# capability-workbench · 双三角 × Feature 能力诊断工作台

> **受众声明：本技能萃取自以太一堂付费课程框架（《AI 双三角》《AI 基本功第一课：Feature 思维》，讲师 Truman），仅限以太一堂学员内部使用，请勿外传。**

## 这是什么

一个**引导式多阶段技能**：让 Agent 扫描你的多个项目（结构、说明文档、git 历史、技能 frontmatter），按「双三角六要素 + Feature 周期律」做证据化判读，经**人工门控（Gate）**决断后，生成：

1. 每个项目的扫描报告（六要素完备度 + Feature 判读 + 待决断清单）
2. 能力评估汇总（段位定位、六角画像、差距与修炼路径）
3. 一个**单文件 HTML 工作台**（双击即开）：双三角模型图（点击六角看证据）、Feature 周期律网格、迭代证据链、Feature Library、资产画布

它**不是**一次性自动生成器：审美、创造力、场景的价值判断由你本人通过封闭式问答（Gate）完成，AI 只判存在性与结构，不清楚的地方会主动停下来问你。

## 怎么装

把整个 `capability-workbench/` 目录放入你的 Agent 技能目录（如 Claude 系的 `~/.claude/skills/`、WorkBuddy 技能目录等），确保 `SKILL.md` 位于 `capability-workbench/SKILL.md`。无需安装依赖；工作台构建仅需 Python 3 标准库。

## 怎么触发

对 Agent 说：

- 「用 capability-workbench 扫描我的这几个项目，做一次能力诊断」
- 「生成我的双三角能力工作台」
- 「帮我做 Feature 周期律归位分析」

并准备好：**待扫描项目的路径清单**；可选：对外展示口径、任务现场材料（用于使用质量深扫）。

## 流程约定（五阶段 + 可选深扫）

1. **准备**：确认项目路径与受众口径（仅自用 / 可对外展示）
2. **扫描**：逐项目产出六要素判级 + Feature 判读报告（多代理并行或单代理串行自适应）
3. **人工门控（强制）**：Agent 汇总「待决断清单」，你逐条封闭式回答（审美锚点、创造力差异标记、场景 go/no-go、判物复核、归因确认、品味规则）
4. **汇总**：能力评估汇总 + 数据 JSON
5. **工作台**：模板注入生成单文件 HTML + 自检

可选阶段：提供 1–3 个真实 AI 协作任务的现场材料，可追加「使用质量」深扫（工具思维 vs Feature 思维诊断、归因破局）。

## 有什么约定

- **人是主体**：Gate 不答，价值定稿不出；未决断项如实标注「待决断」。
- **证据分级**：每个结论带置信档；不可达路径标「待确认」而非「没有」。
- **对外口径**：选择「可对外展示」时，差距清单与低分细节只留评估文档、不进工作台。
- **版权**：课程框架内容（六要素、周期律表）版权归以太一堂，学员内部使用。
