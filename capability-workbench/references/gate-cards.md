# gate-cards · 人工门控操作卡

> 门控是本技能的**强制阶段**：价值判断永远留给人。每张卡 = 输入物（AI 备好）→ 人工动作（封闭式，人只答最小集合）→ 输出物 → 判读规则。

## 引导式交互总原则

1. 扫描中遇到**模糊、冲突、缺证据**的点 → 标记为 Gate 候选，**主动停下来问用户**，等回答再继续。
2. 问题一律**封闭式**（二选一/三选一/填空），避免开放式评审；可附一句备注但非必需。
3. 全部 Gate 可汇总成一张「待决断清单」，让用户**逐条编号+选项**回答（如 `G3: go`）。
4. 收齐回答后**回填**到各扫描报告的 Gate 章节，标注「已决断」；未答的保留「待决断」。
5. Gate 未过的资产仍可进入画像，但如实标注（如创造力「无证据」不扣分不美化）。

## Gate 1 — 审美（锚点对照，AI 不自评）

| 项 | 内容 |
|---|---|
| 输入 | AI 出「质量标准载体清单」；**用户**提供 2–3 个「好版本」锚点（外部标杆或本人满意的历史产出） |
| 人工动作 | ① 锚点是否认可？答 是/否。② 当前资产对照锚点：达标 / 不达标 / 无法对照 |
| 输出 | 审美要素定稿 + 锚点登记 |
| 规则 | 拒绝供锚 → 审美保持 `待确认` 不降级；锚点可同簇复用 |

## Gate 2 — 创造力（差异清单逐条标记）

| 项 | 内容 |
|---|---|
| 输入 | AI 出**差异清单**：逐条列「相对同类惯例的差异点」，一句话一条，不评价价值 |
| 人工动作 | 每条标 有价值 / 无价值 |
| 输出 | 有效差异点计数 + 摘要 |
| 规则 | 清单空或全无价值 → 记 `无证据`（如实）；≥1 条有价值 → 记 `确认`；标注「AI 生成假设，人工已标注」 |

## Gate 3 — 场景终审（ROI 事实底稿）

| 项 | 内容 |
|---|---|
| 输入 | AI 出 ROI 事实底稿：目标客户清晰度 / 封装成本 / 差异化 / 与成熟产品差距——只列事实不评分 |
| 人工动作 | go / no-go（可附一句理由） |
| 输出 | 场景定稿 + 是否进核心画像名单 |
| 规则 | no-go 资产保留并注明原因（如「已有更优版本替代」）；go/no-go 不改资产事实 |

## Gate F1 — 判物抽样复核（Feature）

AI 对候选 Feature 判物与周期律归位后，抽 10–15 个边界案例请用户裁决「合格 Feature / 不合格」。判据：是否针对具体问题、可复用、可验证、长期稳定（工具速朽，Feature 长存）。

## Gate F2 — 归因确认（使用质量诊断）

对「产出不及格」案例的破局假设（如「缺某 Feature 而非模型天花板」），AI 只看现场材料，**真实意图与上下文只有当事人知道**——归因结论必须经用户确认后才标「已确认」。

## Gate F3 — 品味规则供给

主观审美须由用户翻译成**加减分规则**（如「带口语腔 −2」「有数据支撑 +3」），AI 才能执行批量评估。这不是外加门控，而是「审美规则化」方法本身；可与 Gate 1 锚点**一次供给、两边共用**。

## 决断回填规则

- 每条决断写回对应扫描报告：`- G-xx【类型】✅ 决断内容`，翻转改判要**写明原因**（如口径澄清导致的改判）。
- 决断中产生的**规则类结论**（判定规则、口径、方法论）沉淀进评估文档的「决策」章节，供后续复用。
