# Feature 周期律全表（v0.8）

> **来源声明**：萃取自以太一堂《AI 基本功第一课：Feature 思维》（Truman，live258）课程模型图，v0.8 三轮视觉解析誊清版。**仅限以太一堂学员使用，请勿外传。** 课程自注：「编号可自行总结填写、不求全」。

## 怎么读这张表

- **纵轴 5 层（L1→L5）**：自下而上「打好地基、螺旋上升」；每层一条能力跃迁主线：
  - L1 基础模型层：从单一模型到组合参数
  - L2 提示词层：从简单聊天到工程控制
  - L3 能力流程层：从临时对话到重复流程
  - L4 Agent 工作层：从简单对话到员工工作
  - L5 硅基组织层：从单一角色到组织协同
- **横轴 4 维度**：A 角色身份 / B 上下文资源 / C 能力环境 / D 任务协作
- **轴注**：更高追求 ←→ 工作场景；底部注：Feature——从角色到协作，从内部到外部
- **用法纪律**：纵轴「下层能解决就不上上层」；场景「借假修真」——场景是假，Feature 是真

## L1 基础模型层（从单一模型到组合参数）

| 维度 | 子组 | Feature |
|---|---|---|
| 跨维度 | 模型组合 | 底层模型参数、组合模型、切换模型、模型融合、1+1>2 效果 |
| 跨维度 | 参数控制 | 随机种子、结果排名、理性温度、多模态识图、视觉反馈、模型格式化 |

## L2 提示词层（从简单聊天到工程控制）

| 维度 | 子组 | Feature |
|---|---|---|
| 2A 角色身份 | 设定身份 | 赋予角色、用户身份、各方协作身份 |
| 2A 角色身份 | 高阶角色 | 反向提示、反问教我 / 反向采访、反向记录 / 自我批评 |
| 2B 上下文资源 | 上下文增强 | Few-shot 示例、给背景信息 / 联网搜索、给 DataPack / 用 RAG |
| 2B 上下文资源 | 生成标准 | 最终意图、负面提示、给验收标准 |
| 2C 能力环境 | 逻辑控制 | 思维链 CoT、连续多步 CoV、图片输出、条件约束、严格规则 |
| 2C 能力环境 | 优化迭代 | 提示词优化、控制变量、版本管理、链式思维 |
| 2D 任务协作 | 自主任务 | 自动拆解、先提问、N 选 1、自动化测试 |
| 2D 任务协作 | 最终意图 | 明确意图、增加任务 / 目的说明、给整体上下文、多个假设并行 |

## L3 能力流程层（从临时对话到重复流程）

| 维度 | Feature |
|---|---|
| 3A 技能定位 | 环境感知、任务切分 |
| 3B 外部存储 | 检索增强、长期记忆 |
| 3C Skill / 外部工具 | 调用代码 / 函数调用、生成代码、图像 / 语音识别、爬虫读取、API 连接、外部工具 |
| 3D Workflow | 大任务拆解、流程固化、流程调用；LLMs API、SOP 固化、企业知识库 |

## L4 Agent 工作层（从简单对话到员工工作）

| 维度 | Feature |
|---|---|
| 4A 角色配置 | 用户画像、角色身份配置、专业岗位设定、工作边界界定 |
| 4B 长期记忆 | 长期记忆、自进化能力 / 记忆收录、上下文压缩 / 自动判断 |
| 4C 运行环境 | ComputerUse 权限、终端操作 / 文件系统、浏览器操作 / 心跳机制、日志 / 定时任务 / 沙箱 |
| 4D 自主执行 | ReAct / 子任务、结果检查 / 失败恢复、持续推进 Goal / 主动汇报 |
| 4D 工具协作 | IM、网关机制、跨工具协同 |

> 层旁注：**跳出工具，在 Feature 层面工作会获得显著的 10 年 AI 成长复利。**

## L5 硅基组织层（从单一角色到组织协同）

| 维度 | Feature |
|---|---|
| 5A 角色分工 | 角色分工、能力分工、组织整体设计 |
| 5B 共享资源 | 共享资产、共享技能、共享知识库 |
| 5C 环境扩展 | 全局环境、环境总线、自由 Agent 工具 |
| 5D 组织协同 | 任务总线、总线机制、子任务分发、动态协同、组织记忆、自动分工、自动进化、Agent 沟通、Agent 招募 |

## 右侧场景栏（借假修真：场景是假，Feature 是真）

做 PPT、写文案、做图 / 设计、写方案、VibeCoding、做调研、搓 Agent / Coach、AI 落地（作业挖掘 / 个性化运营）、AI 兴趣（哄娃 / 小游戏 / 写歌）……
