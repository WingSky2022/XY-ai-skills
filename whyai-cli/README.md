# WhyAI CLI（`whyai`）本地 Agent 调用技能

> **版本**：v1.14.0（2026-09-21 更新）

封装本地 `whyai` CLI，供各个 Agent 在用户明确授权后调用 YAI / 一堂正式环境。技能负责命令路由、Gateway 校验、JSON 输出与敏感操作边界；不包含 CLI 本体、不保存令牌、不修改其他 Agent 配置。

> 📌 **本文件只是导航索引，不承载规则正文**：所有判据与纪律以 `SKILL.md` 为准。
> 所有判据、纪律与证据的**唯一真相源**是 `SKILL.md` 与 `references/`——为避免双份维护漂移，本文件**不再复制**它们的章节内容。任何冲突以 `SKILL.md` / `references/` 为准。

## 使用范围

- 查询登录状态、账户、模型、配额和用量
- **读取** 会话、消息、笔记、记忆与服务端文件元信息（默认只读，不出境）
- 在明确授权后发送 YAI 请求、继续会话、使用联网搜索或知识库
- 管理对话、消息和文件，并对上传/删除动作执行安全确认
- 审计与清理服务端记忆（`memories list` / `delete` / `clear`）
- 用户明确要求升级时执行 `whyai upgrade`
- 检测不到 `whyai` 时，自动按官方说明安装（Node.js 不满足时停止并报告）
