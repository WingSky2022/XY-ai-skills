# mitv-adclean · 小米/红米电视去广告

一个让 AI 助手替你改造电视的 Agent 技能：经 Wi-Fi ADB 停用电视里的广告/遥测组件，再把电视 DNS 指向带过滤的 DNS，**去掉开机广告与弹窗贴片**。全程无 root、每一步只做可逆操作、停用清单先给你过目确认后才执行。

## 这是什么

智能电视的开机广告和系统级弹窗靠设置里关不干净——它们由系统内置的广告/遥测组件播放。本技能把这些组件的处置过程固化成一套 Agent 流程：

- **Agent 负责技术活**：扫描定位电视、连接采集、诊断广告来源、生成停用清单、执行、验证
- **你只按遥控器**：开发者模式开关、授权弹窗确认、重启电视，仅此而已
- **全程可逆**：只用 `pm uninstall -k --user 0`（用户级卸载，APK 保留）+ `pm install-existing` 恢复；DNS 改回自动即还原

### 适用范围

| 你的电视 | 适用度 | 说明 |
|:--|:--|:--|
| 小米/红米全系（含老款 Android 6 固件） | ✅ 直接适用 | 候选包清单现成，探测 + 降级结构自动适配新老固件 |
| 其他安卓系 TV（索尼/TCL/海信/Google TV 盒子等） | ⚠️ 骨架适用 | 流程原样可用，候选包按「品牌扩展协议」联网调研重建 |
| 三星 Tizen / LG webOS | ❌ 不适用 | 无 ADB，工具体系完全不同 |

## 安装

无任何依赖脚本，把 `mitv-adclean/` 目录整体放进你的 Agent 技能目录即可（例如 `~/.claude/skills/`、`.dsh/skills/` 等你的 Agent 约定位置）。

唯一的外部工具是 **adb**（电脑侧安装，技能流程里会引导）：

- macOS：`brew install android-platform-tools`
- Windows：下载 [Google platform-tools](https://developer.android.com/tools/releases/platform-tools) 并加入 PATH

## 怎么激活

对 AI 说这些话即可触发：

- 「帮我给电视去广告」
- 「小米电视开机广告怎么关」
- 「电视上老弹广告，改造一下」
- 「tv detox」/「cleanyourtv」

## 它会怎么做（流程速览）

```text
Phase 0 扫描定位电视 → Phase 1 引导你开 ADB → Phase 2 连接采集信息
→ Phase 3 断网重启诊断（广告是缓存还是联网拉取）→ Phase 4 停用清单预览 + 你确认 + 执行
→ Phase 5 DNS 过滤设置 → Phase 6 验证固化 → 回滚口令备查
```

三条红线贯穿全程：**永不动系统桌面/设置类组件**（黑屏风险）、**停用清单先给你过目**、**只用可逆命令**。

## 你需要配合的事

1. 电视连进与电脑同一 Wi-Fi；遥控器放在手边
2. 按提示进开发者模式、开「网络 ADB 调试」（技能内置引导话术）
3. 电视弹「允许 USB 调试」时点允许
4. 参与一次 5 分钟的断网重启实验（判断广告来源，决定走哪条路径）
5. 真重启验证：短按电源是待机，不算开机

## 约定与边界

- **停用清单你说了算**：想保留推送、相册、投屏等功能，直接告诉 Agent，它会从清单里剔除
- **视频流内嵌贴片**（如爱奇艺片前贴片）公共 DNS 拦不住，需要自建 AdGuard Home 常驻方案——技能内附完整部署文档（`references/adguard-home-gatekeeper.md`），默认不做、你提出再做
- **官方通道并行可用**：小米客服可登记关闭开机广告，与本方案不冲突
- 已有一台机型的完整实测档案（小米电视 4 / Android 6）随技能附带，供同类老固件参考

## 回滚

```sh
# 恢复任何被停用的包：
adb -s <TV_IP>:5555 shell pm install-existing --user 0 <包名>
# DNS：电视网络设置改回「自动/DHCP」即可。
```

若电视「联网但内容全打不开」，优先怀疑过滤 DNS 不可达——DNS 改回自动即恢复。
